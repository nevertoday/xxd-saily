# 资料来源笔记

规矩在 `docs/MAINTAINING.md` 的「资料来源」：事实只出自 Saily 官方帮助中心；网友的帖子只当作标明出处的经验。这里记读资料时的要点、本站哪页用到，和官方页面自己的毛病。

## 文件

- `official.json`（提交）：每篇官方文章的指纹，键是不带标题的文章地址，值是本地副本的文件名、标题、sha、字数（英文按词，中文按字）。`node scripts/sync-docs.mjs` 更新它，`--check` 只比对。
- `raw/`（只在本地，不提交）：
  - `official/en-us/<id>.md`、`official/zh-cn/<id>.md`：每篇一个文件，开头是标题、分区、网址、更新时间，正文转成 Markdown；带锚点的标题写成 `## 标题 {#锚点}`。
  - `official/_index.md`：按分区列出全部文章，末尾列出只有英文、没有官方中文的文章。
  - `community/`：网友在 X 上的帖子（`article-<id>.md` 是正文，`x-<id>.json` 是抓下来的原始数据）。

## 官方页面自己的毛病（2026-11-19）

- 英文版的「What is an eSIM?」（27276554064924）正文是捷克语，线上页面也是。英文页别链它；中文版正常。
- 只有英文、没有官方中文的 3 篇：Family Plan（29753248333724）、ClassPass with Ultra（31763970183196）、Why should I move my Saily eSIM（31797245183516）。
- 中文版文章里有些链接指向英文版的文章，本站链接时自己换成 `zh-cn` 的地址。

## 写新手页时要记得的几条

- 在中国大陆、香港、澳门、台湾和韩国，很多当地卖的机型不支持 eSIM（12838788763164 的 #travel 一节）。第 1 课要讲，第 6 步「手机不支持 eSIM 怎么办」接着讲。
- 手机不支持 eSIM 时，官方的办法是 eSIM.me 的实体卡，装的时候要找客服要二维码（12822397552028）。
- 套餐要到了它覆盖的国家、打开 Saily 这条线和数据漫游以后才生效；Saily 的 eSIM 走当地合作网络，所以数据漫游必须开着（12838788763164）。
- Saily 的 App 或网站在土耳其、阿曼、卡塔尔、沙特阿拉伯、阿联酋和中国大陆可能打不开，要出发前装好（12838788763164#travel）。本站只引这一句，不教绕过的办法。
- 电话号码要先做 KYC 实名认证，通过之前号码不显示、也不能用（29288111980060 和电话号码那一组）；有的服务会把它当成 VoIP 号码，验证码可能收不到（27948598334620）。

## 网友的帖子

`community/` 里的三篇都是中文教程，讲怎么开美国号码、怎么给不支持 eSIM 的手机写卡。里面有具体价格、代理工具的设置和第三方写卡器的购买建议：价格和代理那部分本站一律不用；写卡器只能当作「有网友这样做过」来提，并附原帖链接，官方的说法以 12822397552028 为准。
